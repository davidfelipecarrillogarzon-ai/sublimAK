# Inventory Management System

## 📌 Description

This is a simple inventory management system developed in Java.
It allows users to register products, manage stock, and record sales using a graphical interface.

## 🚀 Features

* Add and search products
* Manage stock levels
* Register sales with custom or default prices
* Input validation using dialogs
* Persistent data storage

## 🛠️ Technologies Used

* Java
* Swing (JOptionPane)
* File handling

## ▶️ How to Run

1. Clone the repository:

   ```bash
   git clone (https://github.com/davidfelipecarrillogarzon-ai/sublimAK)
   ```

2. Open the project in your IDE (VS Code, IntelliJ, etc.)

3. Compile the project:

   ```bash
   javac src/*.java
   ```

4. Run the application:

   ```bash
   java src/App
   ```
